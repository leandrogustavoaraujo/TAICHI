# Tai Chi em Casa 45+

Um único arquivo `index.html` — código e imagens embutidos, sem
dependências externas além das fontes do Google (precisa de internet só
pra isso).

## Ver funcionando
Dê duplo clique no `index.html`. Abre direto no navegador (testado no
Edge/Chrome via file://, sem bloqueio de módulo).

## Subir no GitHub
Suba esta pasta pro seu repositório normalmente. Dá pra ativar o GitHub
Pages apontando pra ela, ou continuar usando o Vercel — os dois servem
esse arquivo sem problema.
